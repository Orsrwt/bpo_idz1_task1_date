# БПО. ИДЗ 1. Задание 1, вариант 9 — класс Date

Консольное приложение на C# (.NET 8). Класс `Date` для работы с датами
в формате «год.месяц.день»: високосный год, ±дни, сравнение дат,
количество дней между датами. Демонстрируются интерфейс, абстрактный класс,
конструкторы/деструктор, обработка исключений.

## Запуск
```
dotnet run
```
